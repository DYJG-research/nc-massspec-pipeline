三、核心 Python 代码
======================================================================

1. build_broad_preranker_dataset.py
类别：Broad Candidate Pool 主构造代码
作用：
- 最终候选池主程序。
- 统一运行 V3、OLD、Direct 和 V3-F reserved lane。
- 最终 practical broad pool：
  V3 broad Top50 ∪ OLD Top400 ∪ Direct Top5 ∪ V3-F Top15
  然后按 neutral formula 去重。
- 构造 XGBoost 所需的 61 维候选特征。
- 输出 X、y、groups、meta、audit、features、dataset 等 ranking dataset 文件。
状态：FINAL，必须保留。

2. eval_final_candidate_union_2000.py
类别：候选生成底层基础代码
作用：
- 为 Broad Pool builder 提供底层 V3 / OLD / chemical rule 实现。
- 包括 formula parsing、exact mass、adduct、DBE、氮规则、元素比例等。
- 包括或调用 extension signatures、carbon_range_v3、enumerate_chno、
  enumerate_legacy_8、enumerate_extension、build_old、build_direct 等。
状态：FINAL，必须保留。

3. build_formula_nothink_sft_v4_listwise_zh_resume.py
类别：第一阶段 Listwise 数据构造及候选 metadata 代码
作用：
- 第一阶段 Listwise SFT 的关键数据构造程序。
- Broad Pool 特征构造也依赖其中的 best_mass_matched_adduct 等逻辑。
- BestAdduct 是基于候选 formula + precursor m/z + polarity 计算的 latent adduct，
  不是数据中的真实 adduct。
状态：FINAL 依赖。

4. mz_formula_candidates.py
类别：Direct 候选生成底层规则
作用：
- Direct / fragment-guided candidate generation。
- 用 precursor 和 MS/MS fragment evidence 补充候选。
状态：FINAL 依赖。

5. train_xgb_broad_preranker.py
类别：XGBoost 训练代码
作用：
- 使用 candidate-level ranking dataset 训练最终 XGB。
- objective = rank:pairwise
- eval_metric = ndcg@30
- 最终输出模型：preranker_xgb_train20000_val3000.json
状态：FINAL。

6. export_preranker_shortlist.py
类别：XGBoost 推理 / Top30 导出代码
作用：
- 加载最终 XGB。
- 对每个 Broad Pool candidate 打分。
- 全局排序并导出每个 spectrum 的 Top30。
- 正式 test 输出：
  preranker_test17556_all_top30_xgb20k_val3000.jsonl
状态：FINAL。

7. build_override_sft_v3.py
类别：Override V3 数据构造代码
作用：
- 构造最终 V3 train / dev。
- 输出：
  override_sft_v3_train_mixed.jsonl
  override_sft_v3_dev_mixed.jsonl
  override_sft_v3_summary.json
- V3 train 约为：
  SWAP 608 + KEEP 1000 + Listwise replay 300 = 1908。
- SWAP 定义：
  Rank1 != gold 且 Rank2 == gold。
- KEEP 定义：
  Rank1 == gold，或 Rank1 / Rank2 都不是 gold。
状态：FINAL。

8. infer_override_deploy.py
类别：最终 LLM API 推理客户端
作用：
- 调用部署后的 Override V3。
- 仅处理 z < 0.15 的低置信样本。
- 输出 KEEP / SWAP。
- 不允许生成候选池外的新分子式。
状态：FINAL。

9. merge_override_full_test.py
类别：结果合并代码
作用：
- 把 gated subset 上的 KEEP / SWAP 合并回完整 test17556。
- 未进入 gate 的样本保持 XGB 排名。
- 生成 final_test17556_xgb_llm_v3.jsonl。
状态：FINAL。

10. eval_override_v2.py
类别：最终正式六指标 evaluator
作用：
- 当前实验一唯一认可的正式评价程序。
- 正确应用 KEEP/SWAP 后的最终排序。
- 计算 Top-1、Top-3、Top-5、Mass-valid、Formula Validity、Adduct Accuracy。
- Formula Validity 定义为：
  可解析 AND DBE valid AND nitrogen-rule valid AND element-ratio valid。
状态：FINAL，论文和最终结果只认这一版。

======================================================================
十六、最终六指标的正式定义
======================================================================

1. Top-1 Accuracy
最终 Rank1 formula 与真实中性分子式一致的比例。

2. Top-3 Accuracy
真实中性分子式存在于最终前三名候选中的比例。

3. Top-5 Accuracy
真实中性分子式存在于最终前五名候选中的比例。

4. Mass-valid Rate
最终 Top1 candidate 满足：
|ppm| <= 5 ppm

注意：
V3 / Direct 候选搜索可使用 10 ppm，
但正式评价继续用严格 5 ppm。

5. Formula Validity
最终 Top1 formula 同时满足：
可解析、DBE valid、nitrogen rule valid、element ratio valid。

Formula Validity 不等于 Formula Accuracy。

6. Adduct Accuracy
最终 Top1 candidate 的 latent BestAdduct 与 true adduct 一致。
true adduct 仅用于评价，不作为推理输入。
