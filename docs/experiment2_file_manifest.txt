二、论文最终主流程概览
======================================================================

正式主流程：

Exp1 final formula predictions
    ↓
Predicted Formula Top-10
    ↓
independent formula branches
    ↓
SIRIUS 6.3.7 / MSNovelist de novo generation
    ↓
strict branch-level chemical validation
    ↓
Multi-Hypothesis Formula-Lattice
    ↓
Global Formula-Structure Pool
    ↓
Cross-formula XGBoost OOF ranking
    ↓
Selective Qwen3-14B Pairwise Verifier
    ↓
Final Top-10 structures
    ↓
Accuracy / ECFP4 / MCES

正式主模型不包含 terminal rescue。

六、Python 代码：Formula-Lattice 核心原创方法
======================================================================

[VERY IMPORTANT FINAL CODE]

1.
$PROJECT/scripts/80_formula_lattice_predict.py

作用：
Formula-Lattice 的底层化学编辑与 route merge 实现。

主要实现：
- dehydration：formula delta = -H2O；
- acetyl-like removal / deacetylation：formula delta = -C2H2O；
- tri-hydroxylation：formula delta = +O3；
- double reduction：formula delta = +H4；
- RDKit graph edit；
- local structural site score；
- exact target-formula validation；
- connectedness / formal charge / radical / valence checks；
- canonicalization；
- merge_candidate_routes()；
- Top-1 lock 相关底层策略。

这是 Supplementary Methods 中四种 graph-edit operator
具体可复现定义的核心代码来源。

状态：
FINAL CORE CHEMISTRY CODE。


2.
$PROJECT/scripts/140_multihyp_formula_lattice_predict.py

作用：
正式 Multi-Hypothesis Formula-Lattice 主程序。

主要实现：
- current-batch same-formula transfer；
- formula-to-formula neighbor graph；
- cross-spectrum donor selection；
- fragment spectrum preprocessing；
- precursor-relative neutral-loss spectrum；
- spectral similarity；
- same-adduct:
  0.70 direct + 0.30 neutral loss；
- different-adduct:
  0.25 direct + 0.75 neutral loss；
- matched cosine tolerance：
  max(20 ppm, 0.025 Da)；
- donor-rank landmarks：
  1,2,3,5,7,10,14,20,30,50；
- 默认禁止 same-spectrum formula-neighbor editing；
- 调用 scripts/80_formula_lattice_predict.py 的 graph-edit operator；
- original Top-1 lock；
- branch Top-K merge；
- provenance 记录；
- 输出 lattice audit。

状态：
FINAL CORE METHOD CODE。
